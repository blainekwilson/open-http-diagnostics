# AWS Application Load Balancer

AWS Application Load Balancer is an HTTP front door and target router. Its
access logs can be the canonical Level 1 record for Lambda and service targets.

| OHD level | Status | Method |
|---|---|---|
| 1 | Documented | Native access logs exported to the configured destination |
| 2 | Planned | Target-side W3C Trace Context integration |
| 3 | Integration-specific | Target response integration |
| 4 | Planned | Provider and target diagnostics |

Start with [Level 1](level-1.md).
