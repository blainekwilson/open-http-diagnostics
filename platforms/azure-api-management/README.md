# Azure API Management

Azure API Management is an API gateway and policy layer. Its diagnostic logs
may be the canonical Level 1 record when it is the external HTTP boundary.

| OHD level | Status | Method |
|---|---|---|
| 1 | Documented | Gateway diagnostics exported to the configured destination |
| 2 | Planned | Gateway policy and backend W3C Trace Context integration |
| 3 | Integration-specific | Gateway policy or backend response integration |
| 4 | Planned | Gateway and backend diagnostics |

Start with [Level 1](level-1.md).
