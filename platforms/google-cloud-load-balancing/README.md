# Google Cloud Load Balancing

Google Cloud Load Balancing is a family of global and regional HTTP entry
points. Its Cloud Logging request logs may be the canonical Level 1 record for
Cloud Functions, Cloud Run, and other backends.

| OHD level | Status | Method |
|---|---|---|
| 1 | Documented | Cloud Logging load-balancer request logs |
| 2 | Planned | Backend W3C Trace Context integration |
| 3 | Integration-specific | Backend response integration |
| 4 | Planned | Load-balancer and backend diagnostics |

Start with [Level 1](level-1.md).
