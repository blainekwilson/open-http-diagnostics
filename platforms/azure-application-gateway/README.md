# Azure Application Gateway

Azure Application Gateway is a regional HTTP load balancer and reverse proxy.
Its diagnostic access logs may be the canonical Level 1 record for function,
container, and application backends.

| OHD level | Status | Method |
|---|---|---|
| 1 | Documented | Azure diagnostic access logs exported to the configured destination |
| 2 | Planned | Backend W3C Trace Context integration |
| 3 | Integration-specific | Backend response integration |
| 4 | Planned | Gateway and backend diagnostics |

Start with [Level 1](level-1.md).
