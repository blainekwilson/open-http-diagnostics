# Azure Front Door

Azure Front Door is a global HTTP entry point and edge proxy. Its diagnostic
access logs may be the canonical Level 1 record for Azure Functions, App
Service, and other backends.

| OHD level | Status | Method |
|---|---|---|
| 1 | Documented | Azure diagnostic resource logs exported to the configured destination |
| 2 | Planned | Edge and backend W3C Trace Context integration |
| 3 | Integration-specific | Backend or edge response policy |
| 4 | Planned | Edge and backend diagnostics |

Start with [Level 1](level-1.md).
