# Google Cloud API Gateway

Google Cloud API Gateway is an API front door whose Cloud Logging request logs
may be the canonical Level 1 record for function and service backends.

| OHD level | Status | Method |
|---|---|---|
| 1 | Documented | Cloud Logging gateway request logs |
| 2 | Planned | Gateway and backend W3C Trace Context integration |
| 3 | Integration-specific | Gateway policy or backend response integration |
| 4 | Planned | Gateway and backend diagnostics |

Start with [Level 1](level-1.md).
